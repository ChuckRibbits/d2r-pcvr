# Install D2R PCVR

Download the compiled **d2r-pcvr-windows.zip** asset from
[v0.3.0-windows-quest-preview](https://github.com/bearstonem/d2r-pcvr/releases/tag/v0.3.0-windows-quest-preview).
Extract it to a permanent folder and start with
**[INSTALL-WINDOWS.md](INSTALL-WINDOWS.md)**. The guide covers installation,
Steam launch options, Steam Frame/Quest connections, VDXR, body calibration,
controls, upgrading and removal. The ZIP includes the plugin, OpenXR loader,
installer scripts and two VR launch shortcuts. Python 3.10+ is required.

This preview requires the **Steam edition of D2R 3.3.93787** and a **local
offline character**. Normal Steam Play remains stock. No game files or saves
are distributed; icons and potion models are prepared from the user's game.

Steam Frame/SteamVR and Quest 3/Steam Link were tested by the owner. Quest 3
also reached tracked gameplay through Virtual Desktop/VDXR, and the owner
confirmed the sRGB correction restored normal colors. Physical Quest 2,
Virtual Desktop with SteamVR, and Linux/WiVRn remain unverified. See
[steamvr/QUEST_TESTING.md](steamvr/QUEST_TESTING.md) for recorded coverage.

[INSTALL-LINUX.md](INSTALL-LINUX.md) retains Linux/Proton development setup
notes. [WINDOWS_HANDOFF.md](WINDOWS_HANDOFF.md) and [HANDOFF.md](HANDOFF.md) are
development records; the Windows install guide is the user-facing entry point.
Licenses and attribution are in [THIRD_PARTY.md](THIRD_PARTY.md).
